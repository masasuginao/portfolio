# Masanao's Portfolio

This is Masanao's portfolio site, which I converted from my original custom WordPress theme into a static website.

**🔗 Live Demo:** [https://masasuginao.github.io/portfolio/](https://masasuginao.github.io/portfolio/)

## 📖 About the Project
I originally designed and developed a custom WordPress theme using PHP. To make it efficiently hostable on GitHub Pages, I manually converted the dynamic WordPress architecture into a static HTML, CSS, and JavaScript website.

This project demonstrates my ability to:
* Build a responsive website layout from scratch.
* Understand the structure of WordPress themes and convert them into static code.
* Deploy and manage a static site using GitHub Pages.

## ✨ Features
* **Responsive Design:** Fully optimized for both mobile and desktop devices.
* **Grid Layout:** A clean 3-column grid layout for displaying portfolio items.
* **Hero Header:** Full-width hero image with a transparent overlay header.
* **Interactive Menu:** Custom JavaScript hamburger menu for mobile devices.

## 🛠️ Technologies Used
* **HTML5**
* **CSS3** (Flexbox & CSS Grid)
* **JavaScript** (Vanilla JS for navigation)
* *(Original theme built with PHP & WordPress)*
